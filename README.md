# Jaloliddin Ro'ziqulov — Shaxsiy Portfolio (Glassmorphism & 3 Tillik)

Glassmorphism (Polimorfik shaffof oyna effekti) uslubidagi zamonaviy, nafis va professional shaxsiy portfolio veb-sayti.

## 🚀 Imkoniyatlar
- **Glassmorphism / Frosted Glass UI**: Shaffof xira orqa fon (`backdrop-filter: blur(20px)`), nozik neon chekkalar, ichki yorug'lik va orqa fondagi silliq suzuvchi rangli sharlar (`ambient glow`).
- **3 ta Til (UZ | EN | RU)**: O'zbekcha, Inglizcha va Ruscha tillari orasida bir zumda almashish uchun ixcham boshqaruv tugmasi.
- **Qorong'u va Yorug' rejim (Dark / Light)**: Ko'zni charchatmaydigan tinch ranglar palitrasi.
- **HTML5, CSS3, JavaScript (Vanilla)**: Og'ir kutubxonalarsiz, 60fps tezkor animatsiyalar va to'liq moslashuvchanlik.
